# Practice room

User-approved direction: calm light study layout; teal answered numbers, amber flags, green/red results. Build directly in code.

Mode: Operate. A persistent left question index and a readable single-question workspace are the main structure. Set selection uses numbered rows; submitted attempts use an expandable review list.

Warm near-white canvas, pale sage navigation, dark forest text and primary controls. Manrope headings and DM Sans body. Small radii, thin separators, no decorative imagery. Answer identities remain stable when their visual positions are shuffled. On mobile the question index moves above the test and scrolls internally.

Keyboard focus is visible; state labels accompany colors. Multi-answer controls are checkboxes. Submission and replacement of results require a confirmation dialog.
